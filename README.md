# Unc Games

A browser-based collection of classic games like Sudoku, Minesweeper, and more.

## Games

- Sudoku
- Minesweeper
- Solitaire
- 2048
- Chess
- Snake
- Word Search
- Memory Match

## Tech Stack

- Vite
- React
- TypeScript
- chess.js

## Development

Install dependencies:

```powershell
npm install
```

Start the local website:

```powershell
npm run dev
```

Build for production:

```powershell
npm run build
```

## Deployment

The site is configured for GitHub Pages at:

```text
https://abdelrahmanalashel.github.io/Unc-Games/
```

After pushing changes, GitHub Actions will build and deploy the website from `dist`.
